# Rain Detector (Detector de Lluvia)

Proyecto para el curso de Paradigmas de Programación - UNA.

## 📁 Estructura del Proyecto

```text
rain_detector/
├── README.md
├── src/
│   ├── firmware/          # Código del ESP32 / Raspberry Pi / sensores
│   └── backend/           # Servicios, API, base de datos, etc.
├── docs/
│   ├── arquitectura/      # Diagrama(s) de arquitectura del sistema
│   ├── pruebas/           # Evidencias: capturas, fotos, tablas, videos
│   └── justificacion-paradigmas.md
└── bitacoras/

    ├── nombre-apellido-2/
    │   └── bitacora.md
    └── nombre-apellido-3/
        └── bitacora.md
```
